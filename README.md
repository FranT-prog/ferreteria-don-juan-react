# 🔨 Ferretería Don Juan - React SPA

Aplicación Web de Página Única (SPA) desarrollada en React.js para la gestión de una ferretería. 

Este proyecto es la migración a React de un prototipo previo en HTML/JS, cumpliendo con los estándares modernos de desarrollo de componentes y persistencia de datos local.

## Características Principales

- **Catálogo Dinámico:** Visualización de productos renderizados dinámicamente.
- **Carrito de Compras:** Agregado/eliminación de productos, cálculo de totales y simulación de pago.
- **Panel de Administración (CRUD):** Creación, lectura, actualización y eliminación de productos.
- **Persistencia de Datos:** Uso de `localStorage` para mantener el inventario y el carrito guardados tras recargar la página.
- **Rutas Dinámicas:** Navegación fluida sin recargas utilizando `React Router DOM`.

## Tecnologías Utilizadas

- **React.js** (Hooks: `useState`, `useEffect`, `useParams`)
- **React Router DOM** (Enrutamiento y vistas dinámicas)
- **Bootstrap 5 & Bootstrap Icons** (Diseño responsivo y componentes UI)
- **Node.js & npm** (Gestión de paquetes)

## Instalación y Uso

Para correr este proyecto en tu entorno local, sigue estos pasos:

1. Clona este repositorio:
   
cd ferreteria-don-juan-react
npm install
npm start
Abre http://localhost:3000 en tu navegador para ver la aplicación.
